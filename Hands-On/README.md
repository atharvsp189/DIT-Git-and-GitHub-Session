# Student Marks Calculator — Git Hands-On

This small Python project is the starting point for a beginner-friendly Git exercise. You do not need to understand every line of Python; the aim is to practise saving and combining changes with Git.

## Before you start

Check that Git and Python are installed:

```bash
git --version
python3 --version
```

## Run the program

From this folder, run:

```bash
python3 app.py
```

You should see a student-marks summary and a class average.

## Follow the exercise

Open [GUIDE.md](GUIDE.md) and complete the steps in order. The guide shows you how to:

- inspect changes with `git status` and `git diff`;
- save work with `git add` and `git commit`;
- create and merge a feature branch;
- update a branch with `git rebase`; and
- resolve a simple merge conflict.

## Project files

- `app.py` — the marks-calculator program.
- `students.py` — sample student names and marks.
- `GUIDE.md` — the step-by-step Git exercise.
- `.gitignore` — files Git should not track.

## Helpful rule

Run `git status` whenever you are unsure what Git is about to do. It is the safest and most useful Git command for beginners.
