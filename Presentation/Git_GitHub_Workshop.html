Hands-On Workshop
Exercise 1-3: Initialize & Check
💻 LIVE CODING
bash
$ mkdir GitWorkshop
$ cd GitWorkshop
$ git init
Initialized empty Git repository in /GitWorkshop/.git/
$ touch README.md
$ git status
Untracked files: README.md
$ git add README.md
$ git status
Changes to be committed: README.md
Step 1
Create a folder and enter it. This is the project root.
Step 2
Run git init. Git now starts tracking the folder.
Step 3
Create README.md. Check git status. Red means Git sees the file but has not tracked it yet.
Step 4
Run git add. Check status again. Green means it is staged and ready.
Hands-On Workshop
Exercise 4-7: Commit & Log
💻 LIVE CODING
bash
$ git commit -m "Initial commit"
[main (root-commit) a1b2c3d] Initial commit
1 file changed, 1 insertion(+)
create mode 100644 README.md
# Edit README.md now...
$ git status
modified: README.md
$ git add .
$ git commit -m "Updated README"
$ git log
commit b2c3d4e (HEAD -> main)
Author: You <you@example.com>
Date: Today
Updated README
commit a1b2c3d
Initial commit
Step 5: Commit
git commit -m "message" saves a clean snapshot of the project.
Step 6: Modify
Edit the file. Run status again. Yellow means the file has changed since the last commit.
Step 7: History
git log shows the history of the project. Every commit is a checkpoint.
🎯 CHECKPOINT
Do you see two commits in your log? That is the whole idea.
Clarification
Git vs GitHub
They are related, but they do different jobs.
Git
The Tool
✅ Lives on YOUR computer
✅ Tracks code changes
✅ Works offline
✅ Free & open source
✅ Command line tool
vs
GitHub
The Platform
✅ Lives on THE INTERNET
✅ Stores your repositories
✅ Collaboration & social coding
✅ Free for public repos
✅ Website + Desktop app
Alternatives to GitHub: GitLab · Bitbucket · Gitea · Codeberg
GitHub
Connect the Project to GitHub
Once the local history is clean, sending it to GitHub is a short final step.
bash
# 1. Create repo on GitHub (no README)
$ git remote add origin https://github.com/you/repo.git
# Connect the local project to GitHub
$ git branch -M main
# Rename the default branch if needed
$ git push -u origin main
Enumerating objects: 3, done.
Writing objects: 100% (3/3), 245 bytes
To github.com:you/repo.git
* [new branch] main -> main
🎉 Your code is now on the internet!
🌐 git remote add
Points your local project at the GitHub repository.
🚀 git push
Sends your commits to GitHub so the remote copy stays in sync.
📥 git pull
Brings down changes from GitHub when someone else has worked on the project.
🎯 CHECKPOINT
Open your GitHub repo in the browser. If the README appears, the connection worked.

Reference
Git Cheat Sheet
Keep this nearby until the workflow feels automatic.
# Start a project
git init # Initialize repository
# Daily workflow
git status # Check what changed
git add . # Stage all changes
git add filename # Stage specific file
git commit -m "message" # Save snapshot
# History & time travel
git log # View commit history
git log --oneline # Compact history
# Remote (GitHub)
git clone URL # Download project
git remote add origin URL # Connect to GitHub
git push -u origin main # Upload first time
git push # Upload commits
git pull # Download updates
